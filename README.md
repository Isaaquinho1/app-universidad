# Conecta ITT

Conecta ITT es una plataforma institucional desarrollada para el Tecnológico Nacional de México Campus Tlalpan. Su objetivo es centralizar la comunicación oficial, segmentar avisos, integrar calendario académico, directorio, mapa del campus y servicios digitales para la comunidad estudiantil.

## Propósito del proyecto

El proyecto busca transformar un repositorio base de aplicación universitaria en una plataforma móvil institucional orientada al Campus Tlalpan. La aplicación está pensada principalmente para estudiantes y tendrá soporte para dispositivos Android e iOS.

El módulo web se conservará como base para el futuro panel administrativo institucional, desde donde el personal autorizado podrá gestionar avisos, comunicados, contenidos y servicios digitales.

## Plataformas objetivo

- Android: aplicación móvil para estudiantes.
- iOS: aplicación móvil para estudiantes.
- Web: panel administrativo institucional.

## Alcance inicial

La primera etapa técnica se enfoca en institucionalizar el repositorio sin alterar todavía la lógica central de los módulos existentes. Esta fase contempla:

- Cambio progresivo de identidad visible.
- Inventario de referencias al repositorio original.
- Preparación de configuración institucional.
- Documentación de modificaciones.
- Conservación de módulos funcionales existentes.
- Preparación para Firebase institucional.
- Preparación para futura separación entre app móvil y panel administrativo.

## Estado actual

El repositorio se encuentra en proceso de adaptación técnica hacia Conecta ITT. Las referencias originales a MIREA, RTU MIREA, Ninja MIREA, Firebase original y servicios asociados se están inventariando antes de ser sustituidas o desactivadas de forma controlada.

## Nota de atribución

Este proyecto parte de un repositorio base de aplicación universitaria previamente existente. Durante la adaptación se conservarán los reconocimientos, licencias o atribuciones necesarias conforme a la licencia original del repositorio.
