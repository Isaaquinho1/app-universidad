# Conecta ITT

Conecta ITT es una plataforma móvil institucional desarrollada para el
Tecnológico Nacional de México Campus Tlalpan.

Su objetivo es centralizar la comunicación oficial dirigida a la comunidad
estudiantil mediante comunicados segmentados, notificaciones, trazabilidad de
lectura y servicios académicos.

## Plataformas objetivo

- Android.
- iOS.

El repositorio no mantiene aplicaciones para web, macOS, Windows o Linux.

## Funcionalidades principales

- Comunicados institucionales segmentados por carrera, semestre, grupo, rol y
  usuarios específicos.
- Notificaciones push dirigidas a la audiencia seleccionada.
- Estados de trazabilidad por destinatario.
- Confirmación de lectura.
- Panel administrativo para creación, edición y consulta de resultados.
- Métricas de envío y exportación CSV.
- Perfil institucional de estudiantes y personal autorizado.
- Calendario académico, horario, pendientes y servicios estudiantiles.

## Tecnologías

- Flutter y Dart.
- Firebase Cloud Messaging.
- Firebase Core y Cloud Firestore.
- Supabase.
- BLoC y Cubit.
- GoRouter.

## Estado del proyecto

El repositorio fue institucionalizado como Conecta ITT y limpiado de módulos,
servicios, dependencias e identidades operativas pertenecientes al proyecto
base.

El desarrollo activo está enfocado exclusivamente en Android e iOS.

## Atribución

Este proyecto parte de un repositorio de aplicación universitaria previamente
existente. Las licencias, atribuciones y material histórico necesarios se
conservan en el repositorio y dentro de `reference/`.
