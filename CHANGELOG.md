# Changelog

Todos los cambios relevantes de Conecta ITT se documentan en este archivo.

El historial técnico del repositorio base se conserva en
`reference/original_project/CHANGELOG_MIREA.md`.

## No publicado

### Cambios

- Institucionalización del proyecto como Conecta ITT.
- Renombramiento del paquete Dart a `conecta_itt`.
- Configuración de identidad Android para el TecNM Campus Tlalpan.
- Conservación temporal del identificador iOS `com.ituniversity.app` para
  mantener compatibilidad con Firebase, Apple, Supabase y enlaces profundos.
- Implementación de perfiles institucionales y roles.
- Implementación de comunicados segmentados y trazables.
- Integración de notificaciones push mediante Firebase Cloud Messaging.
- Incorporación de métricas administrativas y exportación CSV.
- Eliminación de módulos, servicios y dependencias heredados de MIREA.
- Eliminación del soporte raíz para Linux, macOS, Windows y web.
- Limitación oficial del producto móvil a Android e iOS.
